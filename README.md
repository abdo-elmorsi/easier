<h2>Overview</h2>
<p>easier is a comprehensive developer toolkit crafted to accelerate the development of scalable, feature-rich property management applications. It offers a modular architecture, extensive controllers, and a rich UI component library to streamline complex workflows.</p>
<p><strong>Why easier?</strong></p>
<p>This project simplifies building robust property management systems. The core features include:</p>
<ul class="list-disc pl-4 my-0">
<li class="my-0">🎨 <strong>🖍️ Customizable UI Components:</strong> Reusable elements like buttons, modals, and data tables for consistent, efficient UI development.</li>
<li class="my-0">🌐 <strong>🌍 Internationalization &amp; Theming:</strong> Supports multiple languages and themes, ensuring a personalized user experience.</li>
<li class="my-0">📊 <strong>📥 Data Export &amp; Reporting:</strong> Facilitates exporting reports to Excel and PDF, aiding data analysis and decision-making.</li>
<li class="my-0">💬 <strong>🛠️ Real-Time Chat &amp; Communication:</strong> Built-in chat features for seamless resident and management interactions.</li>
<li class="my-0">🔒 <strong>🔑 Secure Authentication &amp; Authorization:</strong> Robust login, password management, and route protection for user security.</li>
<li class="my-0">📈 <strong>📈 Advanced Data Management:</strong> Centralized APIs, dynamic dashboards, and detailed financial reports to streamline operations.</li>
</ul>

<h2>Getting Started</h2>
<h3>Prerequisites</h3>
<p>This project requires the following dependencies:</p>
<ul class="list-disc pl-4 my-0">
<li class="my-0"><strong>Programming Language:</strong> JavaScript</li>
<li class="my-0"><strong>Package Manager:</strong> Npm, Yarn</li>
</ul>
<h3>Installation</h3>
<p>Build easier from the source and install dependencies:</p>
<ol>
<li class="my-0">
<p><strong>Clone the repository:</strong></p>
<pre><code class="language-sh">❯ git clone https://github.com/abdo-elmorsi/easier
</code></pre>
</li>
<li class="my-0">
<p><strong>Navigate to the project directory:</strong></p>
<pre><code class="language-sh">❯ cd easier
</code></pre>
</li>
<li class="my-0">
<p><strong>Install the dependencies:</strong></p>
</li>
</ol>
<p><strong>Using <a href="https://www.npmjs.com/">npm</a>:</strong></p>
<pre><code class="language-sh">❯ npm install
</code></pre>
<p><strong>Using <a href="https://yarnpkg.com/">yarn</a>:</strong></p>
<pre><code class="language-sh">❯ yarn install
</code></pre>
<h3>Usage</h3>
<p>Run the project with:</p>
<p><strong>Using <a href="https://www.npmjs.com/">npm</a>:</strong></p>
<pre><code class="language-sh">npm start
</code></pre>
<p><strong>Using <a href="https://yarnpkg.com/">yarn</a>:</strong></p>
<pre><code class="language-sh">yarn start
</code></pre>
